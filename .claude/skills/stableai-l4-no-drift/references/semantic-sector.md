# StableAI L4 Semantic Sector Reference

The central mechanism is not caching and not frozen evidence.

It is semantic collapse.

`surface prompt -> semantic microstate -> sector -> canonical representative`

For open-world retrieval:

`different source paths -> same supported semantic core -> same fact sector -> same canonical answer`

The important distinction is:

- retrieval may vary;
- peripheral evidence may vary;
- source wording may vary;
- the stable semantic core should not vary.

The attractor is therefore the minimal semantic survivor that remains valid across admissible evidence variation.

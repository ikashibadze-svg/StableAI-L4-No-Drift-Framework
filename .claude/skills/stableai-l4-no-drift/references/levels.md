# StableAI Control Levels

## L0 — Free generation
No fixed structure. High output freedom.

## L1 — Schema control
Fixed structure/fields. Lexical freedom remains.

## L2 — Constraint control
Schema plus explicit forbidden variation.

## L3 — Canonical style control
Stable vocabulary, ordering, length, and representation rules. Strong compression, but multiple exact survivors may remain.

## L4 — No-Drift control
Schema/state + constraints + repair + canonical attractor/state-space closure + verification.

L4 has multiple operating modes:

- exact-attractor,
- closed canonical derivation,
- canonical open-result control,
- agent/tool execution control.

The invariant is not "always copy a TARGET." The invariant is: eliminate uncontrolled degrees of freedom while preserving the user's task, then verify the relevant result.

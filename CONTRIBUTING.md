# Contributing

Contributions are welcome for bug fixes, validator improvements, benchmark reproducibility, compatibility fixes, and documentation clarity.

Before opening a pull request:

1. preserve StableAI attribution;
2. do not weaken benchmark success criteria;
3. include a reproducible test when changing verification behavior;
4. distinguish measured results from theoretical claims;
5. do not add commercial-use permissions that conflict with `LICENSE.md`.

For new benchmark claims, include the prompt, target, exact model/runtime metadata, requested/completed run counts, raw outputs when possible, and generated report files.
